# Ambition

Speed is what a model gives you for free. This skill spends the effort on the other three directions of **ambition**: **altitude** (the outcome, not the task), **depth** (the way the best practitioner would do it) and **range** (methods from other fields). An **outside judge** keeps the result honest, because a hard bar without a judge only raises the pressure to look successful.

The task is the user's message after `/ambition`, or the current request in the conversation.

## 1. Write the ambition plan

Before any work, write four short sections. Each one names something specific: a goal, a method, a field, a check.

- **Altitude**: the goal behind the goal, and whether the requested task is the best road to it.
- **Depth**: the best practitioner for this work, the raw material they would start from, and their instruments by name.
- **Range**: two or three other fields that would see something here, and what each would *do*.
- **Outside judge**: what, other than your own reading, will show the result is right.

Look up facts yourself (files, data, tools available). Put only decisions to the user.

The plan is done when every section names a concrete thing. "Use best practices" or "be thorough" names nothing: replace it.

## 2. Confirm only what changes the deliverable

If altitude changed *what* gets delivered (a decision memo instead of a deck, a standing process instead of a one-off fix), confirm with the user in one or two sentences. Otherwise start.

## 3. Do the work

Set the bar higher than feels reasonable and treat it as solvable. Reach for the move skills as the work needs them:

- Call the Skill tool with "altitude" to climb from the task to its outcome.
- Call the Skill tool with "depth" for raw material, instruments, assumption checks and target rounds.
- Call the Skill tool with "range" for the crew and the foreign instrument.

## 4. Judge, then report

Call the Skill tool with "outside-judge" before calling the work done.

Close with an honest report: how far you got, what was verified and by which judge, and what is still open. A partial result with its next obstacle named is a good result.
