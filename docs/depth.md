# depth

## What it does

Makes the agent work the way the field's best practitioner would: start from **raw material** (raw data, logs, primary sources), use the practitioner's **instruments** by name (a database, a statistical model, a profiler, a simulation), challenge the belief the task rests on, and work any target in measured **rounds**. When it is deep in data, it looks for something new and tests it on held-out data. It ends with the outside judge.

## When to reach for it

The agent reaches for it when you want something done "properly", "deeper" or at expert level, or when you set a hard target. Type `/depth` to force it.

## Common questions

**What if I don't know what experts use?** You don't need to. The skill names the practitioner and their instruments first.

**What happens when the target is out of reach?** The agent reports the measured number for every round, how far it got, and the next obstacle. That is a legitimate ending.

## It's working if

- You see code, runs and measurements where you used to get tables and prose.
- The agent tells you at least one thing your assumption got wrong, or shows the data supports it.
- Every "faster" or "works" in the report has a number or a check behind it.
